Project Overview

Problem Statement

Higher education institutions need clear, comparable metrics to benchmark performance against peers. This dashboard provides a single interface to explore admissions, enrollment, graduation, and financial aid data from IPEDS.

NJIT uses the platform to understand its competitive position statewide and to surface trends that inform strategic planning and resource allocation.

Target Audience

NJIT institutional research staff, administrators, and developers maintaining the analytics platform.
